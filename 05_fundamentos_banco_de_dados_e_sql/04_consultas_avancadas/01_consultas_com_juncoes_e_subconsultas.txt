Consultas com junções e subconsultas


JOIN
Usado para juntar dados de duas ou mais tabelas relacionadas.

Exemplo:

usuarios
id | nome

reservas
id | id_usuario | destino

Consulta:

SELECT usuarios.nome, reservas.destino
FROM usuarios
JOIN reservas
ON usuarios.id = reservas.id_usuario;

O ON define como as tabelas estão relacionadas.


Tipos comuns de JOIN

INNER JOIN
Retorna apenas os registros que possuem correspondência nas duas tabelas.

LEFT JOIN
Retorna todos os registros da tabela da esquerda, mesmo que não tenham correspondência na outra tabela.

RIGHT JOIN
Retorna todos os registros da tabela da direita, mesmo que não tenham correspondência.



SUBCONSULTA

É uma consulta dentro de outra consulta.

Exemplo:

SELECT nome
FROM usuarios
WHERE id IN (
    SELECT id_usuario
    FROM reservas
);

A consulta interna é executada primeiro.
Depois, o resultado é usado pela consulta externa.
