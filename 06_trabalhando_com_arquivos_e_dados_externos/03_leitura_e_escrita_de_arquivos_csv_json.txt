# CSV

## Módulo `csv`

Arquivos CSV são utilizados para representar **tabelas de dados**.

Eles são muito comuns em:

* Planilhas
* Análise de dados
* Exportação de sistemas

Python possui o módulo `csv`, que facilita a leitura e escrita desse tipo de arquivo.

Com ele podemos:

* Criar arquivos CSV
* Adicionar dados
* Ler informações
* Percorrer linhas e colunas

---

# JSON

## Módulo `json`

JSON é um formato utilizado para armazenar e transmitir **dados estruturados**.

Ele é muito comum em:

* APIs
* Aplicações web
* Armazenamento de dados
* Comunicação entre sistemas

Python possui o módulo `json` para trabalhar com esse formato.

Com ele podemos transformar estruturas de dados Python em JSON e também converter JSON novamente para estruturas que o Python consegue manipular.

---

import csv

# criando um arquivo CSV

dados = [
    ["nome", "idade", "cidade"],
    ["Ana", 25, "São Paulo"],
    ["Carlos", 30, "Rio de Janeiro"],
    ["Maria", 28, "Belo Horizonte"]
]

with open("pessoas.csv", "w", newline="") as arquivo:
    writer = csv.writer(arquivo)
    writer.writerows(dados)




# lendo um CSV

import csv

with open("pessoas.csv", "r") as arquivo:
    leitor = csv.reader(arquivo)

    for linha in leitor:
        print(linha)




import json

dados = {
    "nome": "Ana",
    "idade": 25,
    "cidade": "São Paulo"
}

with open("usuario.json", "w") as arquivo:
    json.dump(dados, arquivo)




# lendo JSON

import json

with open("usuario.json", "r") as arquivo:
    dados = json.load(arquivo)

print(dados)
